# Spark AI

Asistente de IA personal construido con Expo + Gemini + Clerk Auth.

## Features
- 🔐 Google Sign-In (Clerk)
- ⚡ Spark 3.5 Flash & 🧠 Spark 3.1 Pro (Gemini 2.5)
- 📡 Spark Offline (sin internet)
- 🎙️ Entrada de voz
- 📎 Adjuntar imágenes
- 💬 Historial de conversaciones

## Stack
- Expo SDK 54 / React Native
- Express 5 + Gemini API
- Clerk Auth
