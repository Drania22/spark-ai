# Spark AI

Asistente de IA personal construido con Expo + Claude + Clerk Auth.

## Features
- 🔐 Google Sign-In (Clerk)
- ⚡ Spark 3.5 Flash (Claude Haiku 4.5) & 🧠 Spark 3.1 Pro (Claude Sonnet 5)
- 📡 Spark Offline (sin internet)
- 📎 Adjuntar imágenes
- 💬 Historial de conversaciones

## Stack
- Expo SDK 54 / React Native
- Express 5 + Claude API (Anthropic)
- Clerk Auth
